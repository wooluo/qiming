# 启名 · AI 起名

本地网页版 + 安卓 App：**宝宝起名**与**公司起名**两大模式。核心思路——**程序算命，AI 起名，程序复核**：

- **八字五行喜忌（程序排盘）**：出生信息只在浏览器本地排盘（节气精确、复用六爻项目的 bazi 引擎），AI 只收到排盘结论；
- **诗词典籍出处（AI 生成）**：GLM 流式产出 10 个候选名，出处优先《诗经》《楚辞》《论语》《周易》《唐诗宋词》并引用原句；
- **三才五格打分（程序复核）**：内置 960+ 字康熙笔画表与完整 1-81 数理表，AI 自报笔画仅作缺字兜底并标注「未经核验」。

**零第三方依赖**，Python 标准库 + 原生 JS。

## 快速开始

```bash
cd ~/DEV/qiming
python3 app.py
# 打开 http://127.0.0.1:8772
```

手机（同 Wi-Fi）使用：

```bash
python3 app.py --host 0.0.0.0
# 手机浏览器访问 http://<Mac的IP>:8772
```

## 用法

### 宝宝起名（主模式）

姓氏（必填，支持复姓）+ 性别（男/女/中性）+ 出生日期与时辰（**选填**——不填则跳过八字，按字义音律起名，评分权重自动重分配）+ 字数偏好（单名/双名）+ 期望气质（文雅/大气/诗意/简洁）+ 避讳字（逗号分隔，AI 被明确要求禁用且避同音）。

填写生辰后页面实时显示：四柱、五行条形图、宜补五行与判定依据。生成后得到 10 张名字卡：

- 大字名 + 带调拼音 + **总分环形图**（权重明示：五行匹配 40% + 三才五格 30% + 音律 15% + 字义出处 15%；无生辰时为 五格 50% + 音律 25% + 字义 25%）
- 出处引用（典籍 + 原句）、字义寓意、逐字五行与康熙笔画、重名率预估（高/中/低）
- 每卡可展开**三才五格明细**：五格数与吉凶、三才配置（相生=吉、比和=次吉、相克=凶）；未收录字按 AI 自报笔画计算并标注「笔画未经核验」

### 公司起名（次模式）

品牌词/创始人姓氏（选填）+ 所属行业 + 字数与风格偏好。评分数理总格 40% + 音律 30% + 寓意 30%。**结果仅供参考，注册前请自行到工商核名系统查重。**

### 收藏与对比

收藏夹存本地（服务模式在 `data/favorites.json`，App 模式在 localStorage），可勾选 2-3 个并排对比分数、出处与五格；一键「再来 10 个」自动把已出名单附进提示词要求避开；可复制单个名字的完整解读文本。

## 规则与出处

| 模块 | 规则 | 说明 |
|---|---|---|
| 八字排盘 | 年柱立春为界、月柱十二节为界（五虎遁）、23 点起次日子时、五鼠遁时柱 | 天文节气算法（太阳视黄经，Meeus），复用六爻金钱卦项目 `bazi.js`/`engine.js`，与 Python 排盘向量一致 |
| 喜用神 | 行业通行**扶抑简化规则**：统计五行 → 看日主得令（月支本气）→ 身弱补印比、身强泄耗（我生/我克/克我）、中和补最弱，至多两种 | 页面明示为简化规则；子平取用神本需综合全局，此处仅供起名参考 |
| 康熙笔画 | 以《康熙字典》繁体为准；氵=水4、艹=艸6、辶=辵7、阝左=阜8、阝右=邑7、王=玉5、简体映射到繁体笔画 | 内置表覆盖常见姓氏（含 30 个复姓）与常用起名/公司用字约 960 字；未收录字以 AI 自报笔画兜底并标注 |
| 五格 | 天格=姓末+1（单姓）/姓两字之和（复姓）；人格=姓末+名首；地格=名字之和（单名+1）；总格=全名之和；外格=单姓双名「名末+1」、复姓双名「姓首+名末」、复姓单名「姓首+1」、单姓单名固定 2 | 五格剖象法（熊崎氏）通行公式 |
| 1-81 数理 | 内置完整 81 项静态表（大吉 23 / 吉 16 / 半吉 5 / 凶 28 / 大凶 9），>81 按 ((n-1)%81)+1 归位 | 通行五格数理表，断语为传统说法 |
| 三才 | 天人地三格数 mod 10 → 五行（1,2木 3,4火 5,6土 7,8金 9,0水），按生克规则判定（相生=吉、比和=次吉、任一相克=凶） | 规则推导，**不硬编码** 720 全量表 |
| 三才五格分 | 人格 35% + 地格 20% + 总格 25% + 外格 10% + 三才 10%（天格承祖，不单独论吉凶） | 页面展示明细与公式 |
| 音律 / 字义 | AI 自评分（声调搭配、韵母拗口、谐音自查），前端合成 | 提示词中明确举例谐音反例（杜子腾类）要求自查 |

## 配置 AI 服务（设置页）

**GLM 智谱（Coding Plan）**（唯一内置服务）：

- Base URL `https://open.bigmodel.cn/api/coding/paas/v4`，模型 `glm-5.3`，「快速模式」默认开（关闭深度思考）
- API Key 须用**开通了 Coding Plan 的账号**创建「Coding Plan 类型」密钥；个人类型 Key 会报 `429 1113 余额不足`
- API Key 只保存在本机（服务模式在 `data/config.json`，App 模式在本机 localStorage），请求直连对应服务，不经第三方
- 出生信息只用于本机排盘，发送给 LLM 的仅排盘结论文本

## 安卓 App（v1.0.0）

同一套前端（`static/`）通过 [Capacitor](https://capacitorjs.com) 打包：**App 内置排盘与五格引擎（完全离线计算）、经原生 SSE 插件直连 AI、收藏存本机**，无需运行 Python 服务。

```bash
cd mobile && ./build.sh
# 产物：启名.apk（正式签名版）、启名-debug.apk（调试版）
```

- 首次准备：`ln -s ../liuyao/tools tools`（复用 JDK21 + Android SDK），`npm install` 在 `mobile/` 下执行
- 图标与启动页为「朱砂方章 · 白文名字」矢量设计；旧 API 的位图图标由 `mobile/gen_icons.py`（纯标准库 PNG 光栅化）生成
- 正式版签名密钥在 `mobile/qiming-release.jks` + `mobile/keystore.properties`（均不入库，**务必备份**，丢失后无法对已装用户发布升级）
- 权限仅 INTERNET 一项；`allowBackup=false`；适配摄像头挖孔（edge-to-edge 边距 + 状态栏深色图标）

## 项目结构

```
qiming/
├── app.py                # 本地服务：静态页 + 生成流式代理 + 收藏 API（Python 标准库）
├── static/               # 前端（原生 HTML/JS/CSS，无框架）
│   ├── engine.js         # 历法底层（节气/日柱），与 liuyao 同源
│   ├── bazi.js           # 八字排盘（buildChart），与 liuyao 同源
│   ├── xiyong.js         # 喜用神简化规则引擎
│   ├── prompts.js        # 系统提示词（离线直连与服务端共用，单一来源）
│   ├── parse.js          # AI 返回 JSON 健壮解析（围栏/尾逗号/脏数据/降级）
│   ├── data/strokes.js   # 康熙笔画表（姓氏+常用字约 960，简繁对应）
│   ├── data/wuge.js      # 五格计算 + 81 数理表 + 三才生克
│   └── app.js            # 页面逻辑：双模式表单/八字图/10 卡/收藏对比/离线直连
├── mobile/               # Capacitor 安卓工程（www 为 static 的同步副本）
│   ├── build.sh          # 一键 APK
│   └── gen_icons.py      # 旧 API 位图图标生成（纯标准库）
├── tests/                # node（五格/八字/解析/喜用/离线）+ unittest（stub LLM 全链路）
└── data/                 # config.json（含API Key）、favorites.json（运行时生成）
```

node tests/test_xiyong.js                # 喜用神规则自洽
node tests/test_app_client.js            # 离线模式 + 评分合成/卡片渲染 + 原生环境强制离线回归
node tests/test_app_client.js            # 不加 --no-llm 且本机有 LM Studio 时可实测直连
